# openTIT

A decompilation of **Sly Cooper: Thieves in Time** (PS3, BCES01284) into original,
human-readable, native C++ that builds and runs as a PC application.

This is a *decompilation*, not a recompilation. Every function is studied for what
it does and then rewritten from scratch as ordinary C++ — real types, classes and
control flow — with the PS3 system libraries replaced by a small platform layer.
Nothing in this repository executes, emulates or translates the original machine
code, and no game data is included.

## Building

Requirements: CMake 3.16+ and a C++17 compiler (MSVC 2019+, Clang 10+ or GCC 9+).

```sh
cmake -S . -B build
cmake --build build
```

Run `build/opentit` from (or with `OPENTIT_DATA` pointing at) a folder containing the
contents of your own copy's `PS3_GAME/USRDIR`.

## Layout

| Path | Contents |
|---|---|
| `src/crt` | process start-up/termination |
| `src/platform` | PC replacements for the PS3 system libraries (time, threads, files, system events) |
| `src/ape` | Sanzaru's *Ape* engine core (strings, memory, file system, system bring-up) |
| `src/agl` | *Agl* graphics layer |
| `src/sly` | game code |
| `docs/functions.tsv` | every function in the executable (address, size, region) |
| `docs/imports.tsv` | PRX imports resolved to their system library names |
| `docs/CONVENTIONS.md` | how functions are reimplemented and tracked |
| `tools/` | analysis scripts and the progress counter |

## Progress tracking

A function is counted as done when its reimplementation carries a `// @func 0xADDRESS name`
tag. Functions that are still missing keep a `// TODO(0xADDRESS name)` comment and a minimal
stub so the project always builds. `python3 tools/progress.py` recounts and rewrites the
section above.
